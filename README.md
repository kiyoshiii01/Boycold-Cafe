## Project Description
A web-based system for Boycold Café that lets customers order ahead and pick up at the cafe, while the cafe team manages orders, menu, inventory, and sales reports in one place. Designed from the approved Figma prototype.

## Tech Stack
- Frontend: HTML, CSS, JS
- Data: browser localStorage (demo data only, no backend yet)
- Hosting: GitHub Pages
